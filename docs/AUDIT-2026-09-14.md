日期：2026-09-14。状态：本地修复与回归验证；未提交、发布或部署。

## 结论与证据范围

审查覆盖生产插件入口与工具注册、协调与持久化、权限、成果与 Git、监控和自动化、前端请求生命周期、构建及打包文档。审查开始时原有 52 个测试文件、948 项测试通过；随后用故障注入、并发调用、实际 `apply()`/工具入口和独立临时 Git 仓库复现出未覆盖的问题，并修复根因。

`tests/helpers/mounted-plugin.ts` 挂载真实插件入口，Host 服务使用测试替身；这能验证入口接线，不能替代真实 Harness 的端到端验收。`scripts/smoke-host.mjs` 和客户端冒烟检查加载构建产物，使用受控的服务与模块表。旧 [compatibility.md](compatibility.md) 的实机记录仍是历史证据，不自动覆盖此次修订。

## 明确保留的边界

- 尚未进行本次修订在已安装 Harness 中的真实多窗口、真实模型推理和浏览器交互验收；客户端 SSR/模块加载与请求状态测试不等于浏览器视觉验收。
- 模型按会话写入依赖单独的 companion Host writer；本次没有修改已安装 Host，也没有创建该扩展。跨 Host 传输及在线分享服务仍未部署。
- 面板仅支持本机单用户同源访问。loopback/Origin 限制不是账户认证，不能作为公开互联网或多用户权限系统。
- 互斥作用域是同一 Host/数据域；不声称分布式事务或任意崩溃下的 exactly-once。unknown 需要核验原操作，不能新建 ID 盲发。
- 旧 prepared 操作缺少可信 dispatchGuard、或失败 fork 没有可核验子会话绑定时，会拒绝自动恢复；先恢复/核验原资源再明确发起新动作。文件写入不确定而无结果记录时同样先核查目标。
- 文件交接依赖 Host 提供原子写入与规范化路径语义；当前 Patch 只处理已支持的文本差异，遇到未支持语义明确拒绝。
- 工作区当前不是 Git 仓库，未初始化 Git、提交或发布。测试临时 Git 仓库由测试清理；没有留下后台测试服务。

The fixes cover authorization and stale ownership, duplicate dispatch, durable receipts and recovery, atomic file handoff, Git snapshot consistency, automation and report loops, idempotent budget accounting, workflow retries, frontend request races, lifecycle teardown and the panel's local request boundary. Production entry tests mount the actual plugin with controlled Host doubles. The installed Harness, companion extensions, remote transport and sharing deployment were not modified.
