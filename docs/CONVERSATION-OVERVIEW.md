# 会话概览卡与右侧栏：0.2.6 开发规格

本版对应 PRD 2.11 / T46。右侧内容区分为两种：插件自有的宽工作区（用于首页、输出、来源、网页和子智能体预览）以及宿主原生 `details` 工具详情。前者默认在排除左侧导航的会话可用区域中占约 70%，聊天约 30%；后者仍由 Host 管理，Desktop 2.0.3 的已验证范围为 300—520 CSS px。两者不能混称，也不能把插件自有比例写成宿主公开布局 API。标题栏可见侧栏开关注册在 `conversation.session.header.utilities`，紧跟 `Session log`；工作区锚点继续放在 actions 插槽。概览卡宽屏在主会话 owner 的正常文档流中右对齐，聊天滚动区保留完整宽度。

## 原生子智能体（PRD 2.9 / T44）

概览新增“子智能体”，点击进入右侧原生子智能体列表。与现有“委派任务”并列：前者是 DSH 原生子智能体，后者是 Conductor 创建的普通独立会话，数量不得混用。范围为当前会话的直系目录；不会递归抓取整棵任务树。

列表按“运行中”“已结束 / 空闲”“记录不可用”分组，整行悬停高亮和键盘可操作，显示真实名称与宿主状态。每组首屏 10 条，后续每次显示最多 30 条。时间仅取正式 `subagentTiming` 累计值；没有数据就不显示时间，不用 `updatedAt` 猜测完成时间或编造进度摘要。

公开目录只提供 `running / inactive`，不能据此确认成功、失败或中断。“已结束 / 空闲”不等于成功，且不能用选中即清除的 `SessionSummary.completed` 未读提醒计算成功数量。损坏或不可用项禁用跳转，保留问题说明。缺能力、错误与空目录有不同状态。

使用 `ctx.sessions.list.getSnapshot/subscribe` 与 `refreshSubagents(parentId)`；同父多个视图共用一个 5 秒刷新租约，最后使用者卸载释放。不同会话、迟到结果与卸载后结果隔离。原生 `setSubagentCatalogOpen` 是共享布尔状态而非引用计数，不由本插件调用，避免关闭原生菜单的更新。这里只读公开目录，不读取目标历史、私有缓存或恢复 Agent，也不启动模型、发送消息或添加模型监控。

用户点击健康目录条目后再次确认它属于当前父会话，以 `openSubagent({parentSessionId,childSessionId,mode})` 打开原生会话记录。没有此能力时明确报错，不退回普通 `sessions.open` 或猜测路由。子智能体列表复用 T43 的临时 details 生命周期、返回首页、关闭及窄屏抽屉。

实际验证与本机安装状态见 ACCEPTANCE.md 和 DESKTOP-TRYOUT.md。以下保留此前功能规格。

对应 PRD 2.8 / T38—T43。0.2.3 新增独立右侧栏开关与首页，源码及隔离界面 QA 已通过；候选包安装状态另见 Desktop 试用记录。此前 0.2.2 的源码、带 Desktop 容器的布局回归、真实 Host 冷会话 HTTP、候选包及本机安装已验证，实际用户窗口重开确认仍待完成；这些历史证据不自动证明 0.2.3 已完成。本机安装与窗口加载状态见 [Desktop试用记录](DESKTOP-TRYOUT.md)。

“会话概览卡”是本项目的产品名称，不宣称是 Codex 的官方术语。视觉参考为用户提供的聊天右上方圆角卡片，包含输出内容、子智能体和来源。DSH 中普通委派会话与宿主内部子代理是不同对象，因此本项目使用“委派任务”。

本版保留聊天内创建卡片和子会话来源返回链接。概览卡默认常驻显示，不提供关闭按钮；Escape 和点击外部不关闭卡片，旧版保存的收起偏好不再决定其可见性。卡片只占内容所需高度，宽屏宽度为 330 CSS px，并在主会话 owner 的正常文档流中靠右占位；不使用绝对定位或右侧 padding，聊天滚动区保留完整会话宽度，滚动条位于主界面右侧。会话容器可用宽度不足 1080 CSS px 时，在 header 之后的自有容器内按实际卡片高度占位并保持 16 px 边距。长内容在卡片内滚动，不用估算 header padding 代替占位；保留宿主聊天、输入框和左侧导航。

可打开或预览的资源以整行作为点击与键盘操作目标，鼠标移入或键盘聚焦时整行显示灰色背景，不能只让图标或文字有命中区域。点击“输出内容”或“来源”标题，在插件工作区打开对应资源集合；点击具体条目，在同一工作区切换为该资源的预览。右侧内容预览允许关闭，关闭的是侧栏并返回概览，不关闭概览卡。

## 独立右侧栏开关与首页（0.2.3 / T43）

在当前会话标题栏右上方，通过原生 additive header 插槽提供独立侧栏开关。用户不必先点击概览里的某个文件才能打开右侧内容区：首次主动打开时显示侧栏首页（`WorkspaceHome`）。打开后由插件自有工作区承载内容，默认工作区约占会话可用区域 70%，聊天约占 30%，两侧分别保留 300/320 CSS px 最小宽度；可用宽度不足 740 CSS px 时改用避开 Desktop 顶栏的全宽抽屉。关闭右侧栏不关闭概览卡，也不改变概览的常驻偏好；插件加载不自动展开右侧栏。已有概览资源行继续直接打开相应集合或预览。

工作区宽屏显示可访问的垂直分隔条。拖动或按左右方向键调整比例，Home 恢复 70%；比例限制为 20%—80%，仅手动调整后保存本机偏好。窗口缩放、切换资源和会话会保留比例，并根据最小宽度约束重新计算；窄屏抽屉不显示分隔条。工作区从公共 header slot 锚定，卸载、切会话和插槽移除会清除自有 DOM、监听器、CSS 变量和注册。

侧栏开关必须在窄窗口仍可到达：按标题栏按钮与实际会话可视边界测量，若被长标题、来源或窗口缩小挤出，在概览卡顶部右侧显示同一入口并隐藏原位置；有足够空间时恢复标题栏入口，不同时显示两个开关。窄屏侧栏抽屉避开 Desktop 顶栏，不覆盖窗口操作区；关闭抽屉仍保留概览卡。可达性以实际布局计算，不用单一窗口宽度猜测。

首页只提供以下已接入范围内的入口，不显示尚未实现的操作按钮：

| 入口 | 行为与范围 |
| --- | --- |
| 输出文件 | 打开当前会话真实输出集合，与概览的公开记录和登记成果来源一致；不虚构完整工作区文件树。 |
| 来源 | 打开当前会话真实来源集合，沿用当前已加载历史、权限和资源类型边界。 |
| 网页预览 | 显示 URL 输入表单，明确提交合法且不含内嵌凭据的 HTTP(S) URL 后，在受限 iframe 中预览；预览含地址栏、刷新、会话内前进/后退和外部浏览器入口。站点嵌入策略仍可能阻止显示，不绕过限制，也不宣称完整内置浏览器。 |
| 终端 | 使用 Host `ctx.subprocess.spawnTerminal` 在当前会话工作区目录启动交互式 shell（Windows 为 PowerShell，其它平台为 bash）。不是模型工具终端，不启动模型任务。缺少 PTY 能力时显示原因，不提供假控制台。 |
| 工具详情 | 释放插件对 `details` 的临时注册，交还官方工具详情并保持宿主详情入口可用；不选择、执行或伪造工具。没有已选工具时由宿主呈现其空状态。 |

任何文件、图片、网页、集合或子智能体预览的工具栏均可返回侧栏首页，不必先关闭侧栏。插件工作区不依赖 Host 的 `details` 宽度设置；在支持自有 surface 的公开 header slot 中直接挂载。打开工作区或其预览时概览卡隐藏并释放概览占位，关闭后恢复。首页的“工具详情”入口会关闭自有工作区，交还官方 `details`；只读原生可见性探测确认实际详情栏打开时隐藏概览，详情关闭后恢复。切换会话、宿主插槽移除和插件卸载时清除当前首页/预览状态、订阅及资源，不能把上一个会话的集合带入新会话。

上述动作不创建模型任务、不发送会话消息、不运行协调工具，也不改变 T36 的默认委派边界。侧边聊天、Git 审查、完整文件树或 `fileReferences` 搜索仍未接入，不能用空按钮、静态占位页或链接到无关功能冒充。

## 当前已验证范围

| 分区 | 数据和行为 |
| --- | --- |
| 输出内容 | 当前已加载公开记录中成功的文件编辑，以及当前会话相关的已登记成果；标题打开集合，资源行打开右侧预览，可返回产出会话；链接仅接受 HTTP(S)。登记成果仍展示存在性状态，登记不等于验证或验收。 |
| 委派任务 | 按当前会话的控制关系及实际派发关系列出有读取权限的任务；展示当前状态、目录、待介入状态和每次委派回执。点击打开原生会话。 |
| 来源 | 当前已加载的用户链接、图片附件、成功文件读取和结构化网页检索来源；标题打开集合，资源行打开文件、图片或网页预览。排除模型推理、工具原始内容和私有元数据。来源超过四条可展开，历史未全部加载时明确提示。 |
| 未读回执 | 首次及追加委派分别计数，进入概览或查看结果不自动清零；单条或当前显示列表批量标记已读。待介入指标与未读结果分别保留。 |
| 创建与控制 | 用户可直接填标题和指令，使用只读调研、实现功能、检查变更三个模板；默认继承主会话工作区，可明确选择从当前提交创建 worktree。支持补充、排到下一轮、精确停止本轮，以及持续监控开关。 |
| 目录提醒 | 两个及以上正在运行的相关任务共用目录时提示。只证明目录共享，不声称检测了具体文件冲突。Windows 路径比较忽略大小写，POSIX 路径保留大小写。 |

文件点击默认在右侧只读预览，不直接调用 OS 默认应用。远程成果的路径不交给本机文件服务。图片附件只通过宿主正式 `readAttachment` 接口读取，不把附件名称猜成文件路径。未提供可靠路径或附件身份时，明确说明不可预览，不猜测资源。

创建模板只填充输入，不自动派发。worktree 从当前提交开始，不复制未提交修改；非 Git 目录或缺少宿主能力时由共享准备服务明确拒绝，不退回共享目录启动。默认继承和主会话命名规则保持不变。

## 原生右侧栏与预览边界（T42）

原生工具详情仍复用宿主 `ctx.layout.openDetails()` 和会话范围的 `details` 插槽。该插槽已被官方工具详情占用，且为 single 类型；插件仅在没有自有工作区 surface 的兼容回退路径，或用户明确点击“工具详情”时，临时注册较高优先级的预览组件。自有工作区优先使用公共 header slot 的自有 DOM，不为每次资源切换重复注册原生 `details`。关闭、选择“工具详情”、切换会话、宿主插槽移除或插件卸载时释放注册，让官方详情恢复。不得永久覆盖 `details`、改写宿主方法、接管 `root` 或修改 ASAR。

现有 Host 的 `LayoutController` 没有公开的关闭状态订阅，也没有公开设置详情栏宽度的接口；工具详情选择不在公开会话快照中。`observeNativePane(anchor, publish)` 是针对 Desktop 2.0.3 已验证三轨 DOM 结构的只读兼容探测：确认真实右列宽度大于 80 CSS px 且未折叠才发布可见，结构变化时安全返回 false；它不是官方布局状态 API，不读取私有 store，也不写 Host DOM。原生侧栏宽度仍由宿主管理，不能用它替代插件工作区的 70/30 比例。完整侧边聊天、编辑器、Git 审查及完整内置浏览器工作台仍属后续范围。

| 资源 | 读取与呈现 |
| --- | --- |
| UTF-8 文本与代码 | 单文件最大 524,288 字节（512 KiB）；显示最多 200,000 个 UTF-16 代码单元，超出明确标记截断。只读展示，不执行代码。 |
| Markdown | 支持常用标题、段落、列表、代码、强调与 HTTP(S) 链接，并可切换原文；不承诺完整 Markdown 扩展语法。原始 HTML 始终作为文本，不能执行。 |
| 图片附件 | 从当前会话正式 `session.readAttachment(attachmentId)` 接口获得经授权的媒体类型和字节；创建的 Blob URL 在预览卸载或切换时撤销。 |
| 网页链接 | 仅允许无内嵌凭据的 HTTP(S) URL，通过带地址栏的受限 iframe 展示；站点的嵌入策略可能阻止显示，保留“浏览器打开”入口。它不是完整内置浏览器，不绕过站点限制。 |

文件读取绑定 UserUI token 解析出的当前 reader，目标仅为当前会话或仍有读取权限的本机委派会话。相对路径以目标实际 cwd 解析；工作区根和文件均经 Host FileSystem 规范解析，并用 `contains` 验证真实目标，不能以字符串前缀或展示路径代替。工作区外路径、符号链接逃逸、目录、特殊文件、无效 UTF-8、包含 NUL 的二进制及超限内容均拒绝。

读取前后检查权限、绑定、工作区、文件规范身份和版本；最后一次文件 metadata I/O 后仍须复查 token 和当前权限，并在发送响应前不再异步让出。FS provider 生命周期变化时停止旧路由的请求，避免 Cordis 每次读取 service 产生新代理导致身份误判。预览不启动模型、不执行工具、不改文件，也不推进任何模型历史游标。

0.2.2 中，已持久化但没有 live Agent 的会话仍可获得只读 UserUI 身份并预览文件。会话存在性、创建时间与 cwd 仅取自宿主正式 `sessionQuery.listSessions()` 元数据；同一 ID 无唯一有效记录、元数据缺失或身份变化时拒绝。当前会话及已授权本机子会话采用相同的规范路径和文件边界校验；异步元数据查询后继续复查权限与生命周期，不因冷会话而跳过校验。此读取不能恢复 Agent、启动模型、读取 Session JSONL 或私有缓存。

## 每次委派的独立回执

首次 create/fork 的 CompletionReturn 继续保存在 Task 上，保留原创建卡片的能力令牌边界。新版本实际发出的非空 send 指令，将可选 CompletionReturn 保存到对应 Operation 上，不覆盖 Task 的首次回传。

回执固定关联 `operationId + taskId + bindingId + bindingVersion + messageId + armedAt`。同一次操作重试使用同一个身份；相同文字的新指令仍是新操作。旧版本没有记录回执的 send 不补猜、不回填。

后台只观察实际承载该消息的首个 Host turn。公开结果必须出现在 `max(startSeq, messageSeq)` 之后且不晚于同轮 `endSeq`；不能把补充指令被消费前的回答当成它的结果。同一轮消费多条指令时，可以分别记录同轮回执，但不宣称模型逐条独立验收了指令。

未进入公开历史的消息保持等待；送达不明保留 delivery_unknown，不自动重发；已证明失败或撤回且没有消费事实时记为 delivery_failed。returned/delivery_failed 为本次终态，不被后续轮次覆盖。

后台对账不写父会话消息、不启动父模型、不创建 watch、不推进 read/wait/report 游标。读取公开历史前后复查权限和绑定；释放管理后停止未终态对账。冷会话只通过宿主正式公开查询读取，不恢复 Agent，不读 JSONL 或私有缓存。

## 查看结果与已读

“查看本次结果”由明确点击触发，仅返回对应回执绑定轮次的最后一条公开 assistant 文字。一次响应最多 24,000 个 UTF-16 code units，并带 truncated；更长内容可打开子会话查看。回执预览仍限 480，detail/reason 限 240，截断标记计入上限。

已读时间保存在该 Operation 的可选 `overviewReadAt`。只有该操作的原派发会话、仍持有读取权限，才能标记；观察者不继承原派发者的未读回执。标记不修改任何模型读取游标，也不清除真实待介入事项。

## HTTP 与宿主扩展

浏览器通过已有 bootstrap 获取只在当前挂载实例内存中保存的 UserUI 凭据。路由限制 loopback、正确 Host 和同源请求，不接受客户端自报 controller/owner 身份。

0.2.2 的 bootstrap 区分 live Agent 和经正式元数据确认的冷持久会话。冷会话凭据不授予协调工具派发权，返回的可派发 `actions` 为空；创建、发送、停止等协调写操作仍要求 live Agent 及其现有授权，不能为了显示概览或预览自动恢复会话。仅仅 `agents.get(sessionId)` 为空不能证明会话不存在或应被拒绝读取。

| 接口 | 语义 |
| --- | --- |
| `GET /conductor/overview` | 从凭据解析当前会话，只读投影相关任务、回执、成果、监控状态和目录提醒；不读取目标历史。 |
| `POST /conductor/overview` | 请求体为 `{"operationIds":["…"]}`，最多 100 条；确认可见终态回执已读。多余字段拒绝，写入临界区再次验证凭据和读取权。 |
| `GET /conductor/overview/result?operationId=…` | 仅原派发者可读取已确认的本地 returned 回执；公开历史 I/O 后再次校验凭据、可见性及准确消息/轮次边界。 |
| `POST /conductor/preview` | 请求体为 `{"path":"…","sessionId":"可选目标会话"}`；reader 来自 Authorization bearer，省略 sessionId 时使用 reader 会话。只读返回 `{kind:"text",path,text,truncated}`；拒绝多余字段、未授权目标、规范路径越界及读取期间身份变化。 |
| `POST /conductor/terminal` | `{action:"open"|"input"|"close"}`。`open` 在当前会话工作区目录调用 Host `spawnTerminal`；Windows 解析 PowerShell，其它平台解析 bash。`input`/`close` 只作用于同一 reader 的会话。缺 PTY 返回 `NO_PTY`。不启动模型。 |
| `GET /conductor/terminal/output?id=…` | 同一 reader 的 octet-stream；先回放 backlog，再推送后续 PTY 字节。关闭标签或卸载会结束对应进程。 |
| `POST /conductor/panel/action` | 复用已有工具入口处理显式用户操作；共用准备、授权、预算、幂等与精确停止逻辑，不新增第二套写入逻辑。 |

概览最多显示 200 个任务、100 条回执、100 个登记成果，超过时显示截断提示；未读计数可以大于当前显示数。列表截断时按钮显示“标记本页已读”，否则显示“全部标记已读”；操作只作用于当前返回的终态回执。未读终态优先排列，因此确认当前批次后可继续处理剩余未读项。

每个已挂载会话共用一次订阅，默认每 5 秒刷新概览；错误后退到 15 秒，隐藏页面暂停请求；最后一个使用者卸载时取消请求和计时器。只读 UI 刷新不等于父模型监控。打开结果后权限丢失会清除已展示的结果。

概览与工作区锚点向 `conversation.session.header.actions` 和已有聊天节点插槽添加组件；可见侧栏开关向 `conversation.session.header.utilities` 追加到 `Session log` 后。首页、集合与预览仅在显式操作期间临时占用 `details`。读取宿主公开 `useSession(selector)` 投影，使用宿主图标和 `--dsw-alias-*` 主题变量；不改 Desktop ASAR。

### 接口缺失、会话不可用与文件缺失

本轮概览 HTTP 404 的根因是旧 Host 进程启动早于 `0.2.0` 安装，而浏览器刷新后已加载新版前端；旧进程没有注册新版接口。界面必须明确提示“完整退出 DSH Desktop（包括托盘进程）后正常重新打开”，不能只显示“请求未完成 HTTP 404”，也不能把页面刷新说成 Host 重启。此诊断不能泛化为所有 404：预览中的 `FILE_NOT_FOUND` 表示文件已移动或不存在，须保留独立、具体的文案。

0.2.2 另行处理旧实现把“没有 live Agent”等同于“不能签发概览凭据”的拒绝路径；已持久化会话改用正式元数据确认。未知或已删除会话、读取权限失效、元数据不可用和同源校验失败仍须拒绝，不能将所有 HTTP 403 隐藏为成功，也不能把它们误报为需要重启的接口 404。

## 默认行为与明确选择

- 默认：创建后主会话结束本次协调；子会话完成后更新卡片和未读回执，模型不醒来。
- 用户选择“持续监控”：调用现有 watch；重要变化可产生父模型回报并使用模型额度。选择“停止监控”只停回报，子任务继续执行。
- 用户选择“查看本次结果”：只在浏览器显示结果，不将内容自动注入父模型，也不要求父模型重复检查。

“只在完成时让父模型汇总一次”尚未实现为独立模式，不能用持续 watch 冒充。用户现在仍可明确要求主会话读取并汇总已经完成的任务。

### 响应式布局实测补充（0.2.1）

概览通过原生 header additive 插槽挂载，按当前会话可用宽度参与主会话正常文档流，不依赖宿主哈希类名或私有状态。可用宽度至少 1080px 时卡片宽 330px 并靠右占位，聊天滚动区保持完整宽度；较窄时放在聊天上方，内部列表可滚动。1920×1080、1280×720 和 390×844 已实际核对。Host 在极窄窗口隐藏 details 时，显式预览使用临时右侧抽屉；关闭或切会话即释放，概览保持常驻。

### 响应式布局修订（0.2.2 / T42）

上述 0.2.1 记录仅代表当时的浏览器场景。Desktop 兼容/扩展模式实际将 `#root` 设为 `top: 36px` 且带 `transform: translateZ(0)`，内部 fixed 元素的定位基准因此不同于视口；不能把 `getBoundingClientRect()` 的视口坐标直接赋给该 fixed 元素，也不能靠硬减 36 px 修正所有宿主环境。

- 会话容器可用宽度小于 1080 CSS px 时，在 header 所属直属分支之后、聊天滚动区之前放置自有概览容器。容器参与正常文档流且不被 flex 压缩，实际高度随内容变化；概览底部不得超过正文滚动区顶部。错误提示、长标题、来源展开和表单变化不能造成覆盖正文或保留大块估算空白。
- 会话容器可用宽度至少 1080 CSS px 时，概览以 330 CSS px 宽度在主会话正常文档流中靠右占位；不使用绝对定位或额外右侧 padding，聊天滚动区及其滚动条保持完整会话宽度。判断依据是会话容器，不是整窗宽度；左侧导航和右侧预览改变可用宽度时须重新布局。
- 卡片高度受可用窗口空间限制，长列表在卡片内滚动；缩小窗口、打开预览或切换父子会话后，聊天滚动区与输入框仍须可见、可操作。卸载时清除自有容器、布局属性和观察器，不移除宿主节点。
- 验收包含 Desktop 的 36 px transformed 容器、普通浏览器、1080 px 临界值两侧、长父子标题、114 条来源、错误提示、来源/表单展开、预览开关及连续缩放。隔离仿真证据不能表述为用户 Desktop 已加载新版；最终验证状态单独记录。

### 独立首页验收补充（0.2.3 / T43）

验证没有选中资源时仍能由右上角开关打开首页；首页入口分别接到真实集合、URL 表单、会话工作区 PTY 终端与官方工具详情。验证从概览直接预览及从预览返回首页、关闭侧栏后概览仍在、重复开关无重复注册、恢复工具详情与切换会话后的释放清理。空集合、无效 URL、受限嵌入、冷会话和窄窗抽屉均保留明确状态；确认没有模型轮次、消息派发或协调写副作用。0.2.2 的断点与 Desktop 容器回归继续适用，最终源码、Host/browser、包及安装证据分别登记。
